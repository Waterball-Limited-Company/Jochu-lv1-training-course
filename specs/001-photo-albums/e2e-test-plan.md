### US-1 建立相簿並整理照片（優先級：P1）

#### Scenario: S-1-1 建立名為「旅行」的相簿

```gherkin
Scenario: 建立名為「旅行」的相簿
  Given 使用者尚未建立任何相簿
  When 使用者建立一個名為「旅行」的相簿
  Then 「旅行」相簿存在
```

**對應欄位**:

- **US**
  - US-1 建立相簿並整理照片
- **AC / Edge**
  - AC-1-1 建立「旅行」並匯入多格式照片（本則只證建立；匯入見 S-1-6）
- **FR**
  - US1-FR1 系統必須允許使用者建立相簿並命名
- **受測部位**
  - `POST /albums`
- **前置資料**
  - 資料庫尚無任何相簿
- **觀測通道**
  - `POST /albums` 的回應，再讀 `GET /albums`。不要直接查資料表。
- **必須維持不變**
  - 不出現子相簿；尚未加入任何照片
- **本則不驗證**
  - 批次匯入、日期分組、拖放
- **預期 TDD Red**
  - 建立後列表看不到「旅行」
- **API**
  - `POST /albums` 建立名稱為「旅行」的相簿
  - `GET /albums` 確認「旅行」存在

#### Scenario: S-1-6 一次將 JPEG、PNG 與 WebP 加入「旅行」相簿

```gherkin
Scenario: 一次將 JPEG、PNG 與 WebP 加入「旅行」相簿
  Given 已有一個名為「旅行」的相簿
  And 本機有可選的 JPEG、PNG 與 WebP 照片
  When 使用者一次將這些照片加入「旅行」相簿
  Then 該相簿內含剛加入的那些照片
```

**對應欄位**:

- **US**
  - US-1 建立相簿並整理照片
- **AC / Edge**
  - AC-1-1 建立「旅行」並匯入多格式照片（本則只證匯入；建立見 S-1-1）
- **FR**
  - US1-FR2 系統必須允許使用者將照片加入指定相簿
  - US1-FR3 系統必須支援一次選取多張 JPEG、PNG 或 WebP 匯入
- **受測部位**
  - `POST /albums/:albumId/photos`
- **前置資料**
  - 已有空的「旅行」相簿；本機有 JPEG、PNG、WebP 各至少一張
- **觀測通道**
  - `POST /albums/:albumId/photos` 的回應，再讀 `GET /albums/:albumId/photos`。
- **必須維持不變**
  - 照片只屬於「旅行」
- **本則不驗證**
  - 建立相簿、不支援格式拒絕、跨相簿移動
- **預期 TDD Red**
  - 上傳後「旅行」裡看不到剛加入的 JPEG、PNG、WebP
- **API**
  - `POST /albums/:albumId/photos` 批次上傳到「旅行」
  - `GET /albums/:albumId/photos` 確認內含剛加入的照片

#### Scenario: S-1-2 將已歸屬照片改加入另一相簿後只留在目標相簿

```gherkin
Scenario: 將已歸屬照片改加入另一相簿後只留在目標相簿
  Given 使用者已建立相簿 A 與相簿 B
  And 某張照片已屬於相簿 A
  When 使用者將該照片加入相簿 B
  Then 該照片只出現在相簿 B
  And 該照片不再出現在相簿 A
```

**對應欄位**:

- **US**
  - US-1 建立相簿並整理照片
- **AC / Edge**
  - AC-1-2 已歸屬照片改加入另一相簿後只留在目標
  - Edge-G-2 同一張照片不得同時屬於多個相簿
- **FR**
  - US1-FR4 已歸屬照片改加入另一相簿時必須從原相簿移出
- **受測部位**
  - `PATCH /photos/:id`
- **前置資料**
  - 已有「旅行」與「家庭」；要移動的那張照片目前在「旅行」
- **觀測通道**
  - `PATCH /photos/:id` 的回應，再分別讀「旅行」與「家庭」的照片列表。
- **必須維持不變**
  - 同一張照片不得同時屬於兩個相簿；其餘照片歸屬不變
- **本則不驗證**
  - 上傳、拖放、空狀態文案
- **預期 TDD Red**
  - 移動後該張仍在「旅行」，或「家庭」看不到該張
- **API**
  - `PATCH /photos/:id` 把該張改到「家庭」
  - `GET /albums/:albumId/photos` 分別確認只在「家庭」、不在「旅行」
- **Data**
  - 每張照片同一時間只屬於一個相簿，移動時覆寫歸屬

## 假設

- Gherkin 用領域語言；endpoint、頁面、觀測通道只寫在對應欄位。
- 後端／前端是 AC／Edge 的薄切片。整合是各 US 的獨立驗證，真串接，不抄薄切片。
- AC-1-1 拆成 S-1-1（建立）與 S-1-6（匯入）。
- 前置資料用白話；相簿稱「旅行」「家庭」「工作」。
- 觀測通道寫從哪條正式介面看結果：後端用 API 讀回，前端用執行期畫面，整合兩邊都看。
- Gherkin：`When` 只有一條；`And` 只接在 Given 或 Then 後面。整合的 When 可以寫完整驗收路徑。
- S-1-2 同時涵蓋 AC-1-2 與 Edge-G-2；切片表仍拆兩列。
- S-3-1、S-3-3 只寫前端；US-3 驗收才看拖放後重整是否還在。
- 拖放只在同一天的分組內。
